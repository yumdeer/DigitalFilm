## 2. 必须你本人做的 3 件事（我做不了）+ 1 件建议

### 2.1 华为开发者账号实名
1. 打开 https://developer.huawei.com/consumer/cn/ ，用要上架的账号登录；
2. 若未实名：进入「个人中心 → 实名认证」，选择个人（身份证）或企业（营业执照 + 对公验证）；
3. 完成后在「AppGallery Connect（AGC）→ 我的项目」能看到项目入口。

### 2.2 AGC 创建应用 + 申请发布证书（阻塞项）
1. AGC → 我的项目 → 新建项目 → 添加应用：
   - 平台：HarmonyOS（应用）
   - 应用名称：`DigitalFilm`
   - 包名：`com.spektra.spektralab`（必须与工程 `AppScope/app.json5` 里的 bundleName 完全一致，且上架后不可修改）
   - 默认语言：简体中文
2. 「证书、APP ID 和 Profile」→ 新建证书：
   - 先用 DevEco Studio 的 `Build > Generate Key and CSR` 生成 `.p12` + `.csr`（密钥别名、密码请自己保存好，后续升级必须用同一个密钥库）；
   - 上传 CSR → 下载发布证书 `.cer`；
   - 新建 Profile（类型选 Release）→ 绑定包名与证书 → 下载 `.p7b`。
3. 把这三样交给我（或自己填）：`.p12` 的存放路径、密钥别名、密钥密码、`.cer`、`.p7b`。我会把 `build-profile.json5` 切到 release 签名并产出可上传的 `.app` 包。

> 说明：签名证书一旦用于上架，后续所有升级都必须使用同一套 `.p12` + 同一密钥别名，否则已安装用户无法覆盖升级。请务必备份 `.p12` 与密码。

### 2.3 工信部 APP 备案 —— 中国大陆上架必需
- 依据《移动互联网应用程序备案》要求，通过云服务商/接入商备案系统提交（没有服务器也要做「APP 备案」，可选择「无域名/无服务器」的纯应用备案路径）。
- 需要：主体证件、应用名称、包名 `com.spektra.spektralab`、公钥与签名指纹（备案系统会让你填，**这一步需要开发配合导出**，届时告诉我，我从签名证书里导出给你）。
- 备案通过后拿到备案号，在 AGC 提交时填写并「校验」；上架后还需在应用内或商店页面展示备案号并链接备案系统。

### 2.4 软件著作权（软著）—— 非必选，可跳过
- **官方口径**：华为开发者联盟《应用资质审核要求》明确「APP 软件著作权证书为『非必选资质』，但建议您申请……以保护您的知识产权」。**不是上架门槛**，不影响提审。
- 三选一即可（都属非必选）：《计算机软件著作权登记证书》/《APP 电子版权证书》/《软件著作权认证证书》。
- 实际作用：证明版权归属，被投诉抄袭/盗版时作为证据。
- 如要办理：中国版权保护中心 https://www.ccopyright.com.cn/ （自行申请免费，约 2-3 个月）或代理加急（3-10 个工作日）。名称建议与上架名称一致（DigitalFilm）。材料为源程序前后各 30 页、软件说明书、身份证明。

## 3. 隐私政策托管（你选了「免费静态托管」）

已生成 `store/privacy-policy.html`。任选一种方式，约 5 分钟：

**GitHub Pages**

2. 上传 `privacy-policy.html`；
3. Settings → Pages → Source 选 `main` / 根目录 → 保存；
4. 得到地址 `https://<你的用户名>.github.io/digitalfilm/privacy-policy.html`。

**Gitee Pages / 华为云 OBS 静态托管** 同理，只要有公网 HTTPS 地址即可。

1. 把 `Index.ets` 里的 `PRIVACY_URL` 常量替换成该地址（目前是占位地址，**不改会被审核判为无效链接**）；
2. 把 URL 填进 AGC 的「隐私政策网址」和「隐私权利网址」两个字段。

同时请把 `privacy-policy.html` 里的两处占位替换掉（必须与 AGC 登记完全一致）：
- `【开发者名称】`：AGC 实名认证的主体名称（个人姓名或企业全称）
- `【联系邮箱】`：可用的联系邮箱
